# Project Time Machine v0.7.7

This release improves everyday navigation and adds explicitly confirmed cleanup
without changing the application's existing backup and recovery architecture.

- **Compact overview activity panels with scrolling:** recent changes, warnings and
  tasks show up to four entries, with newest entries first and stable tie ordering.
  Change events use compact rows and full-path tooltips.
- **Safe removal of disconnected projects:** administrators can permanently delete
  a disabled project's PTM history, snapshots, archives and owned recovery state
  after typing its exact name. **The project's source directory and source files
  are not deleted.** Active operations or unfinished recovery block removal.
- **Compact backup task history:** four visible entries with internal scrolling,
  distinct statuses and the existing refresh and pagination controls.
- **Safe deletion of individual backup archives with dependency checks:** confirmation,
  project ownership, administrator authorization, protection and usage checks,
  audit records and durable retry journals. Archives required by incremental chains
  or retained restore references cannot be deleted individually. No automatic
  cascading deletion is performed. Independent metadata snapshots remain available;
  snapshots tied to a removed point are marked unavailable.
- **Scrollable backup archive table:** up to five visible data rows with sticky
  headers; existing search, filtering, sorting and pagination remain available.
- UI improvements and targeted regression tests; all new controls and messages
  are translated into English, Russian, Polish and Ukrainian.

No SQLite schema change is required. Existing accounts, configuration, projects,
history, schedules, keys and backups are preserved by the normal updater.
Noncanonical legacy/custom storage bindings are intentionally refused by automatic
project deletion. A failed cleanup requires a new explicit confirmation to retry.

## Linux installation and update

Download `project-time-machine-0.7.7-linux.tar.gz` and `SHA256SUMS`, then run:

```sh
sha256sum --ignore-missing -c SHA256SUMS
tar -xzf project-time-machine-0.7.7-linux.tar.gz
cd project-time-machine-0.7.7
./install.sh
```

To update the default installation using its existing settings and data:

```sh
./install.sh --prefix "$HOME/ProjectTimeMachine"
```

The archive contains installation instructions in English, Russian, Polish and
Ukrainian. Verify a backup of the current installation before updating.
