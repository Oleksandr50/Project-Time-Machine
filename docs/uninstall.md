# Удаление

Нативная установка / WSL:

```bash
$HOME/ProjectTimeMachine/bin/ptm uninstall
```

Останавливается только свой экземпляр, снимается его user-служба и launcher. Config,
state, backups, CAS, keys, projects, logs, update checkpoints и код для возврата
**сохраняются** в прежнем prefix. Это намеренное отключение с возможностью возврата,
а не очистка диска. Повторная установка в тот же prefix сохраняет администратора/историю.

Docker: `docker compose down` только в каталоге своей установки. Bind directories
остаются. Не используйте `down -v` или системный prune ради удаления этого приложения.

Наблюдаемые source directories не удаляются. Не удаляйте WSL-дистрибутив: там могут
быть другие приложения и сохранённые данные. Если нужна полностью новая установка,
выберите новый пустой prefix и отдельные storage directories; решение об окончательном
удалении старых данных принимает владелец после проверки внешних резервных копий.
