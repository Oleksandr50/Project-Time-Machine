# Project Time Machine 0.7.6

[English](README.md) · [Русский](README_RU.md) · [Polski](README_PL.md)

Локальна історія проєктів, перевірені резервні копії та відновлення з підтвердженням
через браузер. FastAPI, Jinja2, SQLite. Linux із Python 3.11–3.13; інтерфейс en/ru/pl/uk.
Є конфігурація Docker; на Windows використовується WSL2, нативної EXE-збірки немає.

## Встановлення

У завантаженому каталозі вихідного коду виконайте звичайним користувачем:

```sh
./install.sh
```

Стандартний каталог — `$HOME/ProjectTimeMachine`. Інший каталог і порт:

```sh
./install.sh --prefix "$HOME/MyPTM" --port 13021
"$HOME/MyPTM/bin/setup"
```

Інсталятор показує адреси інтерфейсів сервера. Стандартний bind — `0.0.0.0`;
у браузері використовуйте справжній IP. Початкове створення адміністратора через мережу
потребує коду з `"$HOME/ProjectTimeMachine/bin/ptm" setup-code`. Наявний пароль зберігається.
Для недовірених мереж використовуйте VPN або HTTPS. [Повна інструкція](INSTALL_UK.md).

Додайте проєкт, створіть Full backup, потім Incremental/Checkpoint. Порівнюйте версії
та перевіряйте preview перед підтвердженням Restore. Перше відновлення випробуйте на
тестовому проєкті. Нестандартні віртуальні середовища та генеровані runtime-файли виключайте явно.

## Можливості й обмеження

Кілька проєктів, ролі та дозволи; snapshots метаданих і з відновлюваним вмістом;
історія й diff; SHA-256, перевірка ланцюга копій, розклад, SQLite Backup API,
необов'язкове AES-GCM; preview, страхова копія та журнал відновлення; Python AST,
евристичний аудит, масковані звіти, перегляд логів і SQLite.

Зміни звичайних файлів можуть зупинити backup. Узгодженість SQLite забезпечується для
окремої бази. Атомарну заміну всього проєкту не гарантовано; перед відновленням зупиніть
запис. Snapshot лише метаданих не відновлює вміст. Маскування розпізнає не всі секрети.
