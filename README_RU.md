# Project Time Machine 0.7.6

[English](README.md) · [Polski](README_PL.md) · [Українська](README_UK.md)

Локальная история проектов, проверяемые резервные копии и подтверждаемое восстановление
через браузер. FastAPI, Jinja2, SQLite. Linux, Python 3.11–3.13; интерфейс ru/en/pl/uk.
Предусмотрены Docker и установка через WSL2; нативной Windows-сборки нет.

## Установка

В скачанном каталоге исходников выполните обычным пользователем:

```sh
./install.sh
```

Программа устанавливается в `$HOME/ProjectTimeMachine`. Другой каталог и порт:

```sh
./install.sh --prefix "$HOME/MyPTM" --port 13021
"$HOME/MyPTM/bin/setup"
```

Установщик показывает адреса интерфейсов сервера. По умолчанию bind — `0.0.0.0`;
в браузере используйте фактический IP. Для первого создания администратора по сети
получите код: `"$HOME/ProjectTimeMachine/bin/ptm" setup-code`.
При существующем администраторе используйте прежние логин и пароль.
Для недоверенных сетей используйте VPN или HTTPS.

[Полная инструкция](INSTALL.md). Добавьте проект, создайте Full backup, затем используйте
Incremental/Checkpoint. Сравнивайте версии и подтверждайте Restore после просмотра изменений.
Первую пробу восстановления выполняйте на тестовом проекте. Нестандартные виртуальные
окружения и генерируемые runtime-файлы исключаются явно в настройках проекта.

## Возможности и ограничения

Несколько проектов, роли и права доступа; metadata-only и восстанавливаемые snapshots;
история и текстовый diff; Full/Incremental/Checkpoint, SHA-256, проверка цепочки и расписания;
SQLite Backup API и необязательное AES-GCM; preview, страховая копия и журнал восстановления;
Python AST, эвристический аудит, маскированные отчёты, просмотр логов и SQLite.

Изменения обычных файлов могут остановить backup. Согласованность SQLite обеспечивается
для отдельной базы. Полная атомарность замены проекта не обещается; перед восстановлением
остановите запись. Metadata-only snapshot не восстанавливает отсутствующее содержимое.
Маскировка не гарантирует распознавания каждого секрета.
